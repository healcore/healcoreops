# Изменения

## 1.10.1

- Исправлена сборка в GitHub Actions: проверка кода шла раньше, чем создавались встраиваемые в установщик файлы, поэтому сборка и релиз 1.10.0 не публиковались. Возможности — как в 1.10.0.

## 1.10.0

- **Простой режим** для обычных пользователей: в меню только главное — обзор, оптимизация и проверка ПК, место на диске, программы, автозагрузка, драйверы, здоровье железа, история. Остальные разделы — в режиме администратора (переключатель внизу меню и в настройках); любой раздел находится через Ctrl+K. Новые установки открываются в простом режиме, при обновлении всё остаётся как было.
- **Меньше собственной нагрузки.** Сведения о железе (PowerShell) собираются, только пока их смотрят, или раз в 5 минут, если включены оповещения о железе; видеокарта NVIDIA опрашивается только при открытой странице. Когда окно скрыто в трей или свёрнуто, система опрашивается раз в 5 секунд вместо 2. В настройках — «Расход самой программы» вместе с окном интерфейса WebView2.
- **Пакет для поддержки** — один zip для сообщения об ошибке: отчёт, инвентаризация, журналы, история изменений, настройки, последние фоновые операции. Путь к профилю и имя пользователя заменяются. Кнопка в «Отчёт и защита», поиск Ctrl+K и `--support-bundle [путь.zip]`.
- **Подпись кода:** сборка в GitHub Actions подписывает релизы — через SignPath Foundation (бесплатно для открытых проектов) или своим сертификатом `.pfx`; программа и установщик подписываются по очереди. Инструкция — `docs/SIGNING.md`, политика подписи и приватности — `docs/CODE_SIGNING_POLICY.md`.
- **Чек-лист тестирования** на реальных машинах — `docs/TESTING.md` и шаблон issue «Отчёт о тестировании».
- Меню чуть шире: длинные пункты («Обновления Windows», «Снимки системы») не переносятся и не обрезаются, в том числе у выбранного пункта.
- Новая графика для README: витрина, анимации истории нагрузки, драйверов, снимков системы и простого режима, обновлённые скриншоты всех разделов.

## 1.9.1

- Здоровье железа обновляется само, пока страница открыта: видеокарта NVIDIA (температура, загрузка, вентилятор, память, потребление) — каждые 2 секунды через nvidia-smi, диски и батарея — каждые 10 секунд.
- Проверка драйверов: NVIDIA и каталог Windows Update опрашиваются одновременно, а не по очереди — быстрее, и в строке хода видно, что проверяются все драйверы, а не только NVIDIA. В конце — список найденных обновлений «устройство: текущая → новая версия».

## 1.9.0

Для пользователя:
- **Здоровье железа** — отдельный раздел: SMART дисков (износ, температура и её максимум, наработка, неисправленные ошибки чтения/записи) с понятной оценкой и советом, износ и циклы батареи, температура, вентилятор и потребление видеокарт NVIDIA (через официальную утилиту драйвера). Температуру процессора не показываем: для неё нужен драйвер уровня ядра, который Защитник Windows считает уязвимым.
- **История нагрузки** — ЦП и память за 3 часа – 7 дней; при наведении видно, какие процессы нагружали ПК в эту минуту, щелчок закрепляет момент. Сводка «кто нагружал больше всего» за период. Хранится локально, по умолчанию 7 дней.
- **Подключения программ** (Сеть → Подключения): какие программы с какими узлами соединены, с именами узлов по обратному DNS.
- **Дубликаты** (Место на диске → Дубликаты): поиск одинаковых файлов по содержимому (SHA-256), удаление лишних копий в Корзину; последнюю копию удалить нельзя, системные папки защищены.

Для администратора:
- **Снимки системы** — снимок «до» и сравнение с текущим состоянием или другим снимком: программы, автозагрузка, службы, задачи, драйверы, открытые порты. Значения не зависят от языка интерфейса.
- **Открытые порты** (Сеть → Открытые порты): кто слушает порт, доступен ли он из сети, отметка портов удалённого доступа, проверка по правилам брандмауэра Windows.
- **Обновления Windows** — доступные обновления с выборочной установкой и ходом по шагам, журнал установок с расшифровкой частых кодов ошибок, пауза на 7–35 дней (с отменой через «Историю»).
- **Инвентаризация** — `--inventory путь.json|путь.csv` и кнопки на странице «Отчёт»: JSON со всеми сведениями или строка в общую CSV-таблицу парка (`%COMPUTERNAME%` в пути, защита от одновременной записи).
- **Оповещения по порогам** — мало места, проблемы и перегрев дисков, перегрев видеокарты, нехватка памяти, износ батареи, ожидающая перезагрузка, остановка служб из списка; уведомление и событие в журнале «Приложение» (коды 2000/2001). Активные оповещения — на «Обзоре».

## 1.8.7

- Прозрачность окна убрана полностью: окно всегда плотное, в цвет темы. Из настроек удалён ползунок «Прозрачность», из кода — системный Acrylic/Mica и всё, что с ним связано.
- Заголовок окна окрашивается под шапку программы (тёмный или светлый), фон окна при запуске сразу в цвет темы — без белой вспышки.

## 1.8.6

- Прозрачность переделана по образцу healcore-project: за окном — системный Acrylic с лёгким тоном, а полупрозрачными становятся только фоновые цвета темы (фон окна прозрачнее, панели и поля плотнее). Тёмная тема остаётся тёмной, светлая — светлой; текст и кнопки всегда непрозрачны.
- Один ползунок «Прозрачность» (0–80 %, 0 — выключено) вместо переключателя и выбора материала; меняется на лету.
- Заголовок окна: при прозрачности — системный, без неё — в цвет программы.
- Windows 10: на время перетаскивания окна Acrylic заменяется лёгким размытием, чтобы окно не подтормаживало.
- Подложка WebView2 прозрачная, но тёмного цвета — без светлой каймы.

## 1.8.5

- Настоящий системный фон Windows 11: материал **Mica** (как у Параметров и Проводника) или **Акрил** (матовое стекло, сквозь которое видны окна). Его рисует сама Windows через DWM: рамка растянута на всё окно, интерфейс лежит прямо на материале, неактивное окно становится плотным — как у системных приложений.
- Убрано наложение старого акрила Windows 10 поверх родного эффекта Windows 11 — из-за него прозрачность выглядела «криво» и запаздывала при перетаскивании окна.
- Шапка, меню и строка состояния лежат на материале, карточки и поля — полупрозрачные нейтральные слои. Ползунок «Плотность» задаёт их затемнение.
- На Windows 10 доступен акрил (Mica там нет), выбор материала скрывается автоматически.

## 1.8.4

- Кнопки «Добавить правило» и другие акцентные кнопки в режиме стекла становились тёмными с тёмным текстом — исправлено.
- Прозрачность переделана: вместо прозрачности всего окна (когда просвечивал и текст) — «стекло». Просвечивают только фоны панелей, текст и кнопки всегда чёткие. Ползунок «Плотность стекла» задаёт силу эффекта.
- Стекло строго чёрно-серое: нейтральная плотная тонировка, обои рабочего стола видны лишь как мягкая светотень, без цвета. Модальные окна всегда плотные.

## 1.8.3

- Трассировка: окно журнала оставалось пустым — пустой список строк приходил как `null` и обрывал обновление окна. Теперь журнал показывает ход трассировки сразу, с первой строки.
- Фоновые операции: сбой внутри операции больше не «подвешивает» окно — ошибка выводится в журнал.
- Трассировка: если ICMP API Windows недоступен, автоматически используется системный `tracert`.

## 1.8.2

- Проверка и установка драйверов идут в фоне, без окна: ход виден строкой в разделе «Драйверы», журнал — по кнопке «Подробнее», по завершении приходит уведомление. Можно продолжать работать в других разделах.

## 1.8.1

- **Драйверы ставятся автоматически, без перехода на сайты.** Видеокарты NVIDIA — последняя версия для вашей модели с nvidia.com, с проверкой цифровой подписи NVIDIA и тихой установкой. Остальные устройства (чипсет платы, Realtek, MediaTek, AMD, Intel) — пакетами производителей из каталога Windows Update по точному идентификатору оборудования. Прошивки BIOS автоматически не ставятся.
- Кнопки «Проверить обновления», «Обновить выбранные» и «Обновить все», чекбоксы у устройств, у каждого — доступная версия, источник и размер.
- **Трассировка сети** переписана: работает через системный ICMP API Windows, без зависимости от консоли и кодировки; показывает имена узлов. «Проверить связь» — настоящий ping (ICMP), при блокировке — проверка по TCP.
- В поле узла можно вставить ссылку целиком (`https://site.ru/page`) — лишнее отбрасывается.
- Исправлена подпись «close» на кнопке в окнах операций.

## 1.8.0

**Для всех**
- **Проверка ПК в один клик**: нагрузка, мусор, защита, синие экраны, драйверы, здоровье дисков и батареи, автозагрузка, ожидающая перезагрузка — со ссылками и быстрыми исправлениями.
- **Место на диске**: самые большие папки и файлы, мусор и кэши с очисткой, удаление в Корзину с защитой системных путей.
- **Программы**: удаление, тихое пакетное удаление, поиск остатков, обновление через winget.
- **Сбои и ошибки**: синие экраны с расшифровкой кода (из дампов и журнала), падения программ, частые ошибки Windows.
- **История изменений** с кнопкой «Отменить».
- **Автоочистка по расписанию**, палитра команд **Ctrl+K**, быстрые действия в меню трея, плашка «Windows ждёт перезагрузки».
- Меню разделов сгруппировано.

**Для администраторов**
- Командная строка: `--apply`, `--report`, `--checkup`, `--clean`, `--maintenance`, `--tweak` с кодами возврата.
- Тихая установка: `/S`, `/ALLUSERS`, `/D=`, `/LOG=`, `/NODESKTOP`; тихое удаление `/uninstall /S`.
- Политики в `HKLM\SOFTWARE\Policies\HealCoreOps` (проверяются ядром), шаблон `.reg`.
- Аудит: журнал событий Windows «Приложение» и файлы журнала.
- Службы и планировщик заданий, сеть (проверка интернета, TCP-пинг, порт, трассировка), безопасность, время загрузки, отчёт HTML/JSON.

**Исправления**
- Registry healer больше не помечает существующие файлы как отсутствующие (пути без кавычек с пробелами, WOW64, переменные окружения, пути без `.exe`).
