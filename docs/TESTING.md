# Тестирование на реальных компьютерах

Автоматические тесты (`go test ./...`) проверяют логику: разбор данных, сравнение
снимков, пороги оповещений, поиск дубликатов, сопоставление драйверов и правил
брандмауэра. Но то, что зависит от самой Windows — SMART, nvidia-smi, Центр обновлений,
брандмауэр, установка драйверов, — можно проверить только на живых машинах.
Этот список — что и в каком порядке проверить перед релизом.

Результаты удобно оформлять как issue по шаблону **«Отчёт о тестировании»**
и прикладывать **пакет для поддержки** (Отчёт и защита → «Собрать пакет для поддержки»).

## Набор машин

Минимум — 3 машины, лучше 5. Каждая строка закрывает свой класс проблем.

| # | Машина | Что проверяем в первую очередь |
|---|---|---|
| 1 | Windows 11 24H2+, NVIDIA, NVMe SSD | драйверы NVIDIA, nvidia-smi, SMART NVMe |
| 2 | Ноутбук: Windows 11, Intel или AMD без NVIDIA | батарея (износ, циклы), драйверы через Windows Update, сон и трей |
| 3 | Windows 10 22H2, жёсткий диск HDD | совместимость с Windows 10, SMART HDD, WebView2 на старой системе |
| 4 | ПК с AMD Ryzen и видеокартой AMD | чипсет AMD через Windows Update, отсутствие температуры GPU (ожидаемо) |
| 5 | Учётная запись **без прав администратора** (любая машина) | ограничения, понятные сообщения, отсутствие падений |

Если есть возможность — одна машина в домене с групповыми политиками (для
`HKLM\SOFTWARE\Policies\HealCoreOps` и `--inventory` в общую папку).

## Перед началом

- Создайте точку восстановления (Обслуживание → «Точка восстановления») — часть проверок меняет систему.
- Ставьте **чистой установкой** (удалите старую версию с `/PURGE`), чтобы проверить первый запуск.
- Отмечайте: ✅ работает, ⚠️ работает с замечанием, ❌ не работает. На ⚠️ и ❌ — снимок экрана и пакет для поддержки.

## 1. Установка и первый запуск

- [ ] Установщик запускается; если подпись ещё не настроена, SmartScreen предупреждает (ожидаемо).
- [ ] После установки открывается **простой режим**: в меню 7 главных разделов, внизу «Показать все разделы».
- [ ] «Показать все разделы» → все разделы; «Простой режим» возвращает 7. Ctrl+K находит скрытые разделы.
- [ ] Тёмная и светлая темы, русский и английский — без «сырых» ключей вида `drv_check`.
- [ ] Тихая установка: `HealCoreOps-Setup.exe /S /ALLUSERS /LOG=setup.log` → код 0, ярлыки для всех.
- [ ] Удаление: Параметры → Приложения → HealCoreOps → Удалить; тихое `uninstall.exe /uninstall /S /PURGE`.

## 2. Высокий риск — проверить обязательно

### Здоровье железа
- [ ] Страница открывается сразу, температура видеокарты NVIDIA меняется каждые ~2 с.
- [ ] SMART: износ, температура, наработка, ошибки — **с правами администратора** заполнены; без них — сообщение «нужны права администратора».
- [ ] Ноутбук: заряд, износ, ёмкость, циклы. Настольный ПК: «Батареи нет».
- [ ] Не-NVIDIA видеокарта: загрузка и память есть, температуры нет, есть пояснение.

### Драйверы
- [ ] «Проверить обновления» не блокирует окно; строка хода: «Проверка всех драйверов (NVIDIA и каталог Windows Update) — …».
- [ ] В журнале проверки есть шаги и NVIDIA, и Windows Update; в конце — список «устройство: текущая → новая».
- [ ] NVIDIA: установка последней версии; после — версия в списке обновилась.
- [ ] Windows Update: установка драйвера чипсета/сети; после — версия обновилась.
- [ ] Галочка «каталог Windows Update» снята → проверяется только NVIDIA, журнал это поясняет.

### Обновления Windows
- [ ] «Проверить наличие» — список за 1–5 минут, окно не блокируется.
- [ ] Установка одного небольшого обновления (например, определений Defender) — ход по шагам, итог.
- [ ] Журнал установок: ошибки с расшифровкой кода (если есть в истории).
- [ ] «Приостановить на 7 дн.» → в Параметрах Windows тоже пауза до той же даты. «Возобновить» снимает. Отмена из «Истории» возвращает прежнее состояние.

### Сеть
- [ ] Трассировка `google.com` — строки появляются по мере прохождения, итог «Трассировка завершена».
- [ ] Пинг узла с закрытым ICMP → результат по TCP с пометкой.
- [ ] «Подключения» — браузер, мессенджеры с именами узлов; обновление каждые 5 с.
- [ ] «Открытые порты» → «Проверить брандмауэр»: у портов появились «разрешает / не разрешает». Включите RDP — порт 3389 с отметкой «удалённый доступ».

### Оповещения
- [ ] Заполните диск до порога (или поставьте порог 99%) → за ~2–3 минуты уведомление и блок «Требует внимания» на «Обзоре».
- [ ] Просмотр событий → Журналы Windows → Приложение → источник HealCoreOps, код 2000/2001.
- [ ] Служба из списка наблюдения (например, `Spooler`) остановлена → оповещение; запущена → оповещение снимается.

## 3. Средний риск

- [ ] **Снимки системы:** снимок → установить небольшую программу (например, 7-Zip) → «Сравнить с текущим»: программа, её служба или задача, если есть. Сменить язык и сравнить снова — ложных «изменено» нет.
- [ ] **Дубликаты:** папка с копиями файлов → группы найдены; «Отметить все лишние копии» → «Удалить» → файлы в Корзине; последнюю копию отметить нельзя.
- [ ] **История нагрузки:** через час работы — график, при наведении — процессы; после перезапуска программы история сохранилась.
- [ ] **Инвентаризация:** `HealCoreOps.exe --inventory \\сервер\inv\парк.csv` с 2–3 машин → одна строка на машину, Excel открывает кириллицу.
- [ ] **Пакет для поддержки:** zip открывается; в файлах нет вашего имени пользователя и пути `C:\Users\<имя>` (поиск по имени в распакованных файлах).

## 4. Собственная нагрузка

- [ ] Настройки → «Расход самой программы»: при открытом окне — проценты ЦП небольшие; видны ядро и WebView2.
- [ ] Закройте окно в трей на 5 минут → в Диспетчере задач HealCoreOps почти не грузит ЦП, `powershell.exe` не появляется постоянно (раз в 5 минут — только если включены оповещения о железе).
- [ ] Окно открыто на странице «Здоровье железа» → PowerShell раз в 10 с (ожидаемо), после ухода со страницы — перестаёт.

## 5. Без прав администратора (машина 5)

- [ ] Программа запускается, вверху «Ограниченные права».
- [ ] Действия, требующие прав, недоступны или дают понятное сообщение, а не ошибку.
- [ ] «Перезапустить от имени администратора» работает.

## 6. Регресс старых разделов (быстро)

- [ ] Проверка ПК, оптимизация памяти, игровой режим.
- [ ] Место на диске: анализ, очистка, восстановление из Корзины через «Историю».
- [ ] Программы: удаление, остатки, обновления winget.
- [ ] Автозагрузка, твики (один твик вкл/выкл с отменой), службы, реестр.
- [ ] Сбои и ошибки, отчёт HTML/JSON, политики (`.reg`-шаблон).

## Что делать с результатами

1. Каждую ❌ — отдельный issue с пакетом для поддержки.
2. ⚠️ — одним issue «Замечания тестирования vX.Y.Z».
3. Релиз — когда в разделах 1–2 нет ❌ ни на одной машине.
